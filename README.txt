Northern Beaches General Maths — Papers Society Answers

WHAT'S INCLUDED
- 2020–2024 QCAA General Mathematics
- Paper 1 multiple-choice answers
- Individual short-response question links
- Reveal-answer buttons
- Cropped QCAA marking-guide excerpts so students see the answer for the selected question rather than the whole marking guide
- Mobile-friendly layout
- Shareable hash links such as #2024/p1/q16

HOW TO USE LOCALLY
Open index.html in a web browser.

HOW TO PUT IT ONLINE WITH GITHUB PAGES
1. Create a new public or private GitHub repository (public is simplest for Pages).
2. Upload the CONTENTS of this folder, keeping the assets folder beside index.html.
3. In GitHub: Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. GitHub will provide the final website address.
7. Once the site is live, create one QR code pointing to the main website address.

UPDATING IT
You can add later years or topic-practice sections without changing the QR code, as long as the website address stays the same.
